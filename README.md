# Smiling Dash — Godot 3.5 project

A fresh, Godot 3.5-compatible prototype of Smiling Dash: neon endless runner, smiling cube player, triple jump, spikes, score, game-over and restart.

## Open
1. Install Godot 3.5 Standard (not Godot 4).
2. Open `project.godot` with Godot 3.5.
3. Press F6/F5 to run the game.

## Android export
1. Install the official Godot 3.5 export templates (`.tpz`) in Editor > Manage Export Templates.
2. Configure Android SDK and debug keystore in Editor Settings.
3. Add an Android export preset and set Min SDK to 21 (or the minimum you need and that the template/toolchain supports).
4. Export APK and test on a real Fire device before uploading to Amazon.

## Important
- This is a recreated prototype based on the known Smiling Dash gameplay notes, not a conversion of the exact Godot 4.7.2 project. Original artwork and scene assets from that project were not available in this chat.
- The project uses built-in drawing only; no third-party game assets.
- Exporting an APK has not been performed here, so the Android SDK/template setup and Amazon compatibility still need testing.
